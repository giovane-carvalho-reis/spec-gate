# FR-002 — Validar a especificacao por comando, com exit code

## Descrição
Um comando analisa a pasta do projeto e responde se a especificação está pronta. Cada
pendência cita o gate que a origina e o arquivo onde está. O exit code permite uso
automatizado.

## Critérios de aceitação
- [ ] Dado um projeto que satisfaz os 10 gates, quando valido, então exit code é 0
- [ ] Dado qualquer gate violado, quando valido, então exit code é 1 e cada pendência cita gate e arquivo
- [ ] Dado um caminho que não é diretório, quando valido, então exit code é 2
- [ ] Dado um artefato cujo `id` difere do nome do arquivo, quando valido, então G8 acusa
- [ ] Dado um `satisfies` apontando para ID inexistente, quando valido, então G3 acusa
- [ ] Dado qualquer validação, quando executo, então nenhuma chamada de LLM é feita

## Fora deste requisito
Corrigir o que foi encontrado. O validador relata; quem corrige é o autor ou o agente.
Coerência de sentido também fica fora — isso é FR-008.
