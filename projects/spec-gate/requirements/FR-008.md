# FR-008 — Revisar coerencia de sentido entre artefatos

## Descrição
O validador verifica estrutura; esta capacidade verifica sentido. A revisão lê a pasta
inteira em contexto isolado e devolve apenas os achados, sem consumir a janela principal.

## Critérios de aceitação
- [ ] Dado um requisito que não serve nenhum critério de sucesso do briefing, quando reviso, então é apontado como escopo inflado
- [ ] Dado um critério de sucesso sem requisito que o cubra, quando reviso, então é apontado como lacuna
- [ ] Dado um critério de aceitação que viola uma regra de negócio, quando reviso, então a contradição é apontada com os dois IDs
- [ ] Dado um termo do glossário usado com outro significado, quando reviso, então é apontado
- [ ] Dada uma revisão, quando devolvo o resultado, então devolvo achados e não o conteúdo lido
- [ ] Dado um projeto coerente, quando reviso, então o resultado é "nenhum achado"

## Fora deste requisito
Corrigir os achados. Cada um vira pergunta ou mudança proposta ao autor.
