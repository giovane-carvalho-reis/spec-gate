# BR-005 — ID de artefato e estavel e nao se reaproveita

## Enunciado
O ID do artefato é igual ao nome do arquivo e é imutável. Número de artefato removido não
é reaproveitado por um artefato novo.

## Condição de aplicação
Vale para todos os prefixos: `FR`, `NFR`, `BR`, `UC`, `ADR`, `TC`, `PR`.

## Exceções
Nenhuma. ID reaproveitado faz referência antiga apontar para conteúdo novo sem que nada
acuse o erro — a rastreabilidade continua tecnicamente íntegra e semanticamente falsa.

## Origem
Decisão do autor. Consequência de o nome do arquivo ser a chave primária do sistema.
