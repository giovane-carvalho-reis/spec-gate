# ADR-002 — Sem aplicacao web; o agente de IA e a interface

## Status
Aceita.

## Contexto
A visão previa plataforma web com 11 módulos: Kanban, editor, orquestrador, motor de
diagrama, motor de exportação. Duas restrições se confirmaram depois: nenhum banco
(ADR-001) e uso individual. O autor já usa Claude Code e OpenCode diariamente.

## Decisão
Não há aplicação, servidor nem interface gráfica. O agente de IA, conduzido por
`AGENTS.md`, é a interface. Os módulos da visão são resolvidos por arquivo, git e script.

## Alternativas consideradas
| Alternativa | Por que não |
|---|---|
| Monólito modular com UI web | Sem banco e sem segundo usuário, não resta o que o servidor faria |
| CLI interativo além do agente | O agente já pergunta e escreve melhor que um prompt de terminal |
| TUI para navegar artefatos | `grep` e o editor do autor já fazem isso |

## Consequências
**Ganhos:** o mesmo agente que especifica implementa depois, sem transferência de
contexto. Kanban vira campo de estado, aprovação vira edição de arquivo, exportação vira
git. Zero código de interface para manter.

**Custos e novas restrições:** nenhuma visão consolidada de progresso além de
`project.yaml` e do validador. Quem não usa agente de IA não usa este produto.

**O que fica mais difícil depois desta decisão:** entregar isso a alguém não técnico.
Exigiria construir a plataforma descartada.
