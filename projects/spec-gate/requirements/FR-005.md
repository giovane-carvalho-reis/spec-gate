# FR-005 — Gerar artefato por etapa a partir de template

## Descrição
Cada etapa tem instrução própria que orienta a geração do seu artefato a partir do
template correspondente, com rastreabilidade preenchida no momento da criação.

## Critérios de aceitação
- [ ] Dada uma etapa, quando gero o artefato, então uso o template daquele tipo sem inventar estrutura
- [ ] Dado um artefato novo, quando o crio, então `satisfies`, `verified_by` e `source` já vêm preenchidos
- [ ] Dado um artefato novo, quando o crio, então o nome do arquivo é igual ao `id`
- [ ] Dado um número de artefato já removido, quando crio um novo, então não reaproveito aquele número
- [ ] Dada a instrução de uma etapa, quando a carrego, então não carrego instrução das outras etapas

## Fora deste requisito
Decidir o conteúdo. A instrução define forma e critério de qualidade; o conteúdo vem do
briefing e da entrevista.
