# NFR-003 — Portabilidade e ausencia de servico externo

## Atributo
Portabilidade.

## Métrica
O repositório funciona com Python 3.11+ e exatamente duas dependências (`pyyaml`,
`jsonschema`). Nenhum serviço, banco, container ou credencial. Verificável: validar e criar
projeto com a rede desligada.

## Consequência de não atender
Cada dependência de serviço é uma forma de o projeto parar de funcionar por motivo alheio.
Especificação precisa durar mais que a infraestrutura de quem a escreveu.
