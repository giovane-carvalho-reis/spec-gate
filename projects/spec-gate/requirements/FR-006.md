# FR-006 — Exigir aprovacao humana explicita por etapa

## Descrição
Cada etapa tem estado próprio e só `approved` passa o gate. A promoção é ação humana
deliberada, registrada no arquivo de controle do projeto.

## Critérios de aceitação
- [ ] Dada uma etapa em qualquer estado diferente de `approved`, quando valido, então G4 bloqueia
- [ ] Dado um artefato `proposed`, quando valido, então G7 bloqueia
- [ ] Dada uma etapa `approved` cujo documento não existe, quando valido, então G9 bloqueia
- [ ] Dada uma etapa `approved` cujo documento ainda tem placeholder do template, quando valido, então G9 bloqueia
- [ ] Dada uma etapa `approved` cuja pasta de artefatos está vazia, quando valido, então G9 bloqueia

## Fora deste requisito
Impedir tecnicamente que a IA edite o arquivo de controle. A garantia é de processo, não
de permissão de arquivo — o gate detecta, não previne.
