# FR-009 — Entregar o PSP ao projeto de implementacao

## Descrição
Com os 10 gates verdes, a pasta do projeto é o pacote de especificação. É entregue como
pasta versionada, sem etapa de exportação ou conversão de formato.

## Critérios de aceitação
- [ ] Dado um projeto com exit code 0, quando entrego a pasta, então ela é autossuficiente — nenhum artefato referencia arquivo fora dela
- [ ] Dada a pasta entregue, quando o agente de implementação a lê, então cada fatia do plano é executável sem ler o PSP inteiro
- [ ] Dada a pasta no GitHub, quando a abro no navegador, então todo diagrama renderiza sem ferramenta externa
- [ ] Dado um projeto com qualquer gate vermelho, quando tento entregar, então a entrega não é considerada válida

## Fora deste requisito
A implementação em si, e qualquer automação de transferência entre repositórios.
