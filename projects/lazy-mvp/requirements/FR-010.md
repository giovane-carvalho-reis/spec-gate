# FR-010 — Promover a trilha de light para full

## Descrição
Projeto que cresceu durante o discovery pode passar a exigir as etapas da trilha completa,
sem perder o que já foi aprovado.

## Critérios de aceitação
- [ ] Dado um projeto `light`, quando promovo para `full`, então as 6 etapas novas entram como `pending` e as já aprovadas permanecem `approved`
- [ ] Dado um projeto `light`, quando promovo, então os documentos das etapas novas são criados a partir dos templates
- [ ] Dado um projeto `full`, quando tento rebaixar para `light`, então a operação é recusada
- [ ] Dado um projeto promovido, quando valido, então os gates passam a exigir as etapas da trilha `full`

## Fora deste requisito
Rebaixamento, proibido por BR-003. Trilha intermediária entre `light` e `full`.
