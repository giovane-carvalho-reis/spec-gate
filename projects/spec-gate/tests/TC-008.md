# TC-008 — Validacao de 100 artefatos cabe no orcamento de tempo

| | |
|---|---|
| Verifica | NFR-002 |
| Nível | integração |
| Tipo | limite |
| Implementado por | `test_validate.py`, caso rotulado `TC-008` |

## Pré-condição
Projeto sintético com ~100 artefatos, todos íntegros e com as referências fechadas — para
que o tempo medido seja o da varredura completa, não o de um curto-circuito em erro.

## Passos
1. Gerar 49 `FR-*` e 49 `BR-*`, cada regra referenciada por seu requisito.
2. Medir a validação com `time.perf_counter`.

## Resultado esperado
Exit 0 e tempo abaixo de 2 segundos. O teste falha se o orçamento for estourado, não
apenas avisa — NFR sem instrumento que barre é desejo.
